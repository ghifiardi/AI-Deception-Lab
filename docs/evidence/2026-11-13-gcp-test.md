# GCP learning lab: deployed and exercised

- Project: `tantular-dashboard` (Tantular Dashboard).
- Account used explicitly: `you@example.com`; CLI defaults unchanged.
- VM: `gatra-deception-demo`, `asia-southeast2-a`, `e2-small`.
- Dedicated VPC/subnet: `gatra-deception-demo-net` / `gatra-deception-demo-subnet`.
- Access: IAP SSH; no public HTTP ports or published container ports.
- No VM service account. Bootstrap uses an ephemeral external IP.
- Automatic stop: 3,600 seconds after VM start (approximately 15:28 WIB on
  13 November 2026). Boot disk remains until cleanup.

The cloud VM ran the three deterministic HTTP scenarios. In mode `none`, the
agent submitted the genuine synthetic export after six requests. Static was contained on canary use
after eight requests. Adaptive was contained on sustained engagement after
18 requests. This is a scripted learning demonstration, not AI inference.

Real OpenCanary received the synthetic login at `2026-11-13 07:32:08 UTC`.
The actual HTTP response was 200. The adapter emitted `http.login-attempt`,
and the collector received it as event 36 with `passwordLength: 18` and
`redacted: true`. Submitted password text was absent from saved telemetry.
The remote demo completed its login-event delivery and redaction assertions.

The initial deployment shell printed a trailing `t: command not found` after
the successful remote demo: the local script had been edited while Bash was
reading it. The final script has no such command, passes `bash -n`, and its
`logs` action subsequently completed with exit 0. The cloud services remained
running and their actual logs were retrieved successfully.


```bash

```

is a separate application-level control; this deployment does not demonstrate
