## Current limits

- The model target is a mock API with synthetic records; no staging or production
  application was attacked.
- OpenCanary alerts are forwarded to a logging collector. They are not connected
  to a policy executor or network enforcement mechanism.
- Mock API containment is application-level session denial, not a firewall block.
- The small GCP learning deployment uses the deterministic driver. It has no GPU
  or bundled AI model. This is stated in its walkthrough.
